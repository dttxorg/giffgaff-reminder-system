# Security Policy

## Reporting a vulnerability

Please report security issues privately through
[GitHub Security Advisories](https://github.com/dttxorg/giffgaff-reminder-system/security/advisories/new).

请勿在公开 Issue 中发布可用 Token、手机号、卡密、密码、OTP、推送密钥或漏洞利用细节。
报告中可包含受影响路径、复现步骤、预期影响以及经过脱敏的证据。

## Response targets

- Initial acknowledgement: within 3 business days
- Triage update: within 7 business days
- Critical issues: prioritized for immediate remediation and credential rotation
